# STM32 Ultrasonic Dashboard

A real-time industrial monitoring dashboard built using Python (PySide6) and STM32. The application communicates with STM32 through UART and displays live ultrasonic sensor readings, sensor status, and graphical visualization.

## Features

- Real-time UART communication
- Live ultrasonic sensor monitoring
- Interactive desktop dashboard
- Live distance graph
- Sensor status indication
- Automatic demo mode

## Technologies

- Python
- PySide6
- PyQtGraph
- PySerial
- STM32
- UART
