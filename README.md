# STM32 Ultrasonic Dashboard

A real-time industrial monitoring dashboard built using Python (PySide6) and STM32.

## Features

- Live UART communication with STM32
- Real-time ultrasonic sensor monitoring
- Interactive dashboard UI
- Live distance graph
- Sensor status (Safe / Warning / Danger)
- Auto demo mode when STM32 is unavailable

## Technologies Used

- Python
- PySide6
- PyQtGraph
- PySerial
- STM32
- UART Communication
- com0com (Driver) COM5 > COM7
